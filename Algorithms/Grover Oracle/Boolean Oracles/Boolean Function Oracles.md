#Q-Sharp #Algorithm 
Bool func oracles in Q# - primitive building blocks for [[Grover]], [[SAT oracle]], & [[Graph coloring oracle]]. All follow the **marking [[Oracle]]** pattern: flip `target` iff the func is $1$ on `register`.
1. [[AND Oracle]]
2. [[Majority Oracle]]
3. [[OR Oracle]]
4. [[Parity Oracle]]
5. [[Single-Bit Check]]
6. [[Threshold Oracle]]
7. [[XOR Oracle]]
