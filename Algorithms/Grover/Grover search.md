#Algorithm #DB #Math
See [[Grover]] for the full algorithm description, circuit, and iteration count derivation.

**Problem statement**: given $f: \{0,1\}^n \to \{0,1\}$ as a black-box [[Oracle]], find $x_0$ with $f(x_0) = 1$ using as few queries as possible. [[Grover]]'s algorithm solves this in $O(\sqrt{N})$ queries vs $O(N)$ classically.
