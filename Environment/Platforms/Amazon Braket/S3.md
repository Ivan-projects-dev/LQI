**S3 bucket** is required for all cloud simulator & QPU jobs on [[Amazon Braket]]. Results are written to S3 before being returned. Without a bucket in the correct region, cloud jobs fail.
### Creating the Bucket
1. Go to AWS Console $→$ S3 $→$ Create bucket
2. Set bucket name (globally unique, e.g. `amazon-braket-results-yourname`)
3. Set region - must match your Braket workspace region (e.g. `us-east-1`)
4. Leave all other settings at defaults - no public access, versioning off
```python
from braket.aws import AwsDevice
from braket.circuits import Circuit

device = AwsDevice("arn:aws:braket:::device/quantum-simulator/amazon/sv1")
circuit = Circuit().h(0).cnot(0, 1)
task = device.run(circuit, shots=1000, s3_destination_folder=("amazon-braket-results-yourname", "experiments/bell"))
result = task.result()
print(result.measurement_counts)
```
### Region Mismatch - Silent Failure
If the bucket is in a different region than your Braket workspace, the job fails with a `ValidationException` or hangs indefinitely. No useful error message. Fix: bucket & workspace must be in the same AWS region.

Check your workspace region in AWS Console → [[Amazon Braket]] → top-right region selector.
### LocalSimulator Needs No S3
`LocalSimulator` runs entirely in-process. No S3, no AWS account, no cost:
```python
from braket.devices import LocalSimulator
device = LocalSimulator()
result = device.run(circuit, shots=1000).result()  # no s3_destination_folder
```
Always dev & debug on `LocalSimulator`. Only add S3 when moving to cloud simulators or QPU.
