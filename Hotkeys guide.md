**Problem $1$**: it is impossible to assign $2$ different actions on $1$ hotkey
**Problem $2$**: most of simple & intuitive hotkeys combinations are already taken by Obsidian & its plugins
**Problem $3$**: `Ctrl+Z` will redirect to [[broken links output]] page (all alternative hotkeys were immediately forgotten)

| Hotkey                          | Action                                             |
| ------------------------------- | -------------------------------------------------- |
| `Ctrl+P`                        | Command Palette                                    |
| `Ctrl+O`                        | Quick switcher (open any note by name)             |
| `Ctrl+F`                        | Search in current file                             |
| `Ctrl+Shift+F`                  | Global search across vault                         |
| `Ctrl+G`                        | Open graph view                                    |
| `Ctrl+Alt+B`                    | Open backlinks panel                               |
| `Ctrl+\`                        | Toggle left sidebar                                |
| `Ctrl+B`                        | Bold                                               |
| `Ctrl+E`                        | Toggle reading/editing view                        |
| `Ctrl+I`                        | Italic                                             |
| `Ctrl+K`                        | Insert link                                        |
| `Ctrl+Alt+T` (Templates plugin) | Insert template                                    |
| `Ctrl+Z`                        | [[broken links output]]                            |
| `Ctrl+Shift+Z`                  | Redo                                               |
| `Tab`                           | Indent (in lists)                                  |
| `Shift+Tab`                     | Unindent                                           |
| `Ctrl+N`                        | New note                                           |
| `Ctrl+Shift+N`                  | New note in new pane                               |
| `Ctrl+W`                        | Close current tab                                  |
| `F2`                            | Rename current note                                |
| `Ctrl+Alt+←`                    | Navigate back                                      |
| `Ctrl+Alt+→`                    | Navigate forward                                   |
| `Ctrl+Tab`                      | Switch to next tab                                 |
| `Ctrl+Shift+Tab`                | Switch to previous tab                             |
| `Ctrl+R`                        | Delete orphanized images                           |
| `Ctrl+M`                        | Remove all internal links for this note            |
| `Ctrl+~`                        | Remove all internal & external links for this note |
